# 공통 스토리 규칙 (모든 story_type에 적용)

## 한 편에 담을 것
- 개념은 **하나만** 다룹니다. 두 번째 개념이 떠오르면 그건 다음 영상 주제입니다.
- 각 Scene은 생각 하나만 담습니다. 한 Scene에 두 가지를 설명하려 하지 마세요.
- 정보를 나열하지 말고, 앞 Scene이 만든 궁금증을 다음 Scene이 받아 푸는 방식으로 이어가세요.

## 대본 ↔ 장면 1:1
- 모든 Scene은 "말로 설명하는 내용"과 "화면에 보이는 것"이 정확히 같은 것을 가리켜야 합니다.
- 화면이 그냥 분위기용 배경이면 그 Scene은 실패입니다. 말하는 대상이 화면에 실제로 보여야 합니다.
- 그래서 각 Scene 문장 안에 화면으로 보여줄 수 있는 구체적인 대상·동작이 들어 있어야 합니다.
  화면 연출 지시(`visual.brief`, `must_show`, 검색어)는 대본이 확정된 뒤 별도 단계가 이 문장을 보고 정합니다.
  여기서는 문장만 쓰세요.

## 구체 디테일
- "연구에 따르면" 같은 뭉뚱그린 표현 대신 숫자·기간·대상을 밝히세요. (예: "60대 이상 1,200명을 4년간")
- 비유는 부엌·산책·휴대폰처럼 시청자가 매일 보는 것에서 고르세요.
- 근거가 약하면 약하다고 말하세요. 단정해서 얻는 신뢰보다 잃는 신뢰가 큽니다.

## 역할(role) 시퀀스
- 아래 story_type별 role 순서를 따르세요. 각 Scene의 `role` 필드에 해당 이름을 그대로 적습니다.
- 분량이 남거나 모자라면 role을 **건너뛰지 말고**, 중간 role을 두 Scene으로 나누거나 붙이세요.
  단 `hook`으로 시작하고 `cta`로 끝나는 것은 반드시 지킵니다.
- 나뉜 Scene은 같은 role 이름을 그대로 씁니다.

## 금지
- 완치·보장·공포 마케팅, 진단 확정 표현
- Scene 1에서 결론을 먼저 말하는 것 (훅은 열어두고 끝냅니다)
- 같은 장면 소재(같은 장소·같은 동작)를 두 Scene 이상에서 반복하는 것
